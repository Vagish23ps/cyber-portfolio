## Git training workflow

```bash
git init
git add .
git commit -m "Initial portfolio"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/vagish-portfolio.git
git push -u origin main
```

Create feature branches for future changes:

```bash
git checkout -b feature/project-section
git add .
git commit -m "Update project section"
git push -u origin feature/project-section
```

Then open a Pull Request on GitHub and merge it into `main`.
